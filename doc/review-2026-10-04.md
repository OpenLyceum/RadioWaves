# Code review — 2026-10-04

Reviewed simulation models, input and rendering paths, recording/time behavior, disposal, preferences, bootstrap/configuration, and existing tests. This was a static review supplemented by unit regressions and short browser smoke runs, not an exhaustive proof of correctness.

## Findings addressed

- **P2 — transmitter jumps on entering manual mode:** the manual strategy held an old drag position. It now starts at the current transmitter position with cleared derivative history.
- **P2 — stale oscillator controls across mode changes:** edits made in manual mode were ignored, and queued edits could survive a mode switch. Entering oscillation applies the current controls; switching strategies clears obsolete queued edits.
- **P2 — incorrect oscillator velocity:** the sinusoidal derivative omitted amplitude. Velocity now scales with amplitude and is zero for zero amplitude.
- **P2 — visualization disposal leaks:** field-lattice and plot-trace listeners remained on global colors after disposal. Subscriptions now use node disposal, and the plot disposes its owned trace. WeakRef regressions cover repeated disposal cycles.
